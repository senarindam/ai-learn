# AI Learn

A lightweight static website for learning AI basics through audience-specific
paths. The guide keeps the main journey within three clicks:

1. Choose an audience.
2. Choose a topic: LLM, SLM, or Agents.
3. Read a vivid example and a practical action.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.
